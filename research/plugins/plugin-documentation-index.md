# Índice de documentación oficial de plugins — Sandbox Prototype

**Fecha de investigación: 2026-10-19.** **Alcance: 27 ítems** — 23 plugins/herramientas de la nueva base y 4 sistemas de Moonville para integrar al final.

> **Regla de trabajo:** antes de sugerir propiedades, nodos, pasos de integración o cambios, abrir **primero la documentación del proveedor registrada acá**, revisar la versión instalada del plugin y contrastarla con los assets reales. Avanzar de a un cambio verificable. No confundir la ficha comercial de Fab con un manual técnico.
>
> **Evidencia:** Enlaces a sitios/documentos del fabricante localizados o enlazados desde su ficha de Fab al 2026-10-19. Eso **no verifica** que todas las versiones instaladas sean las más recientes, ni que todos los documentos sean accesibles sin JavaScript o autenticación, ni que todos los 23 plugins pasen una prueba funcional individual. Los cuatro de Moonville aún no están instalados en el nuevo Sandbox.

**4. Black Eye Camera.** Documento Google enlazado oficialmente desde Fab (redirige vía bit.ly; no se pudo leer su contenido desde el navegador). Tutorial de inicio también en Fab. **Fuente:** **Enlace oficial con acceso al texto no comprobado**.

## Documentación integrada y relacionada (nativa de Epic)

Esta sección no agrega plugins al inventario de 27. Incluye dependencias técnicas y marcos nativos involucrados en la integración de Moonville y el Sandbox.

- [Enhanced Input](https://dev.epicgames.com/documentation/en-us/unreal-engine/enhanced-input-in-unreal-engine) — entrada para gameplay.
- [Common UI](https://dev.epicgames.com/documentation/en-us/unreal-engine/common-ui-plugin-for-advanced-user-interfaces-in-unreal-engine) — widgets, acciones y navegación.
- [Gameplay Ability System](https://dev.epicgames.com/documentation/en-us/unreal-engine/gameplay-ability-system-for-unreal-engine) — requerido para las pruebas que lo necesiten, como GAS Companion/Combo Graph.
- [PCG Framework](https://dev.epicgames.com/documentation/en-us/unreal-engine/procedural-content-generation-framework-in-unreal-engine) — sistema base de PCGEx.
- [StateTree](https://dev.epicgames.com/documentation/en-us/unreal-engine/overview-of-state-tree-in-unreal-engine) — sistema base de State Tree Tools.
- [Unreal Plugins](https://dev.epicgames.com/documentation/en-us/unreal-engine/plugins-in-unreal-engine) — instalación, habilitación, módulos y configuración.
- [HTTP Blueprint (nativo)](https://dev.epicgames.com/documentation/en-us/unreal-engine/API/PluginIndex/HttpBlueprint) — **distinto** del bundle comercial UForge; el requisito de Moonville `HTTP, JSON and WebSocket Networking` también debe comprobarse por su identidad de plugin.
- `JSON Blueprint Utilities` — dependencia nativa separada en el setup anterior de Moonville.

## Moonville: fuentes específicas e integración

La documentación primaria es la versión **Common UI** de Menu System Pro y los otros tres documentos oficiales enlazados en la tabla. En el contexto del proyecto ChatGPT se recibieron también cuatro PDFs, pero **no están copiados a este repositorio**; sus nombres exactos constan arriba para encontrarlos sin inventar rutas públicas.

- [Registro histórico Moonville UE 5.8](moonville-stack-integration.md): contiene el baseline anterior, no debe tomarse como el estado del nuevo Sandbox C++.
- [Proyecto Sandbox](../../projects/sandbox-prototype.md): estado de instalación, validación, packaging y backups.
- Cuando retomemos Moonville, comparar la guía de integración `Menu + Inventory + Inspection System` con los Blueprints del **nuevo** proyecto; el manual y los assets pueden diferir.

## Control de calidad pendiente

1. Confirmar `VersionName` de cada `.uplugin` (si aplica) y versión de assets en Fab. Este índice identifica fuentes, **no hace auditoría de versiones instaladas**.
2. Para **Animation Tools Bundle**, investigar si Attaku ofrece documentación técnica más allá de Fab, foro y videos.
3. Para **Black Eye Camera**, **Ultimate Gameplay Camera** y **Global Variable System**, confirmar lectura del documento desde una sesión autenticada si el navegador no lo muestra; la procedencia del link sí está respaldada por el autor.
4. Para **Low Entry Extended Standard Library**, el repositorio público es fuente primaria; no se identificó manual técnico mantenido por separado.
5. Si un enlace oficial cambia o queda obsoleto, buscar la nueva URL desde el fabricante/Fab y actualizar **este archivo** antes de dar indicaciones.
6. No copiar PDFs o documentación propietaria al repositorio sin verificar permisos; mantener enlaces a la fuente y nuestras notas experimentales originales.
