# Video checklist — 60–90 second brief video

The video is the part most people will see. Its job is to show **the result working, and the number behind it**, fast.

## Structure

| Time | Content |
|------|---------|
| 0–10 s | **Hook:** the question as on-screen text, with the final result already visible behind it |
| 10–25 s | **Setup:** one sentence: what was tested, with which engine version |
| 25–70 s | **Demo:** the result working; key number overlaid (time, interventions, frame time…) |
| 70–90 s | **Verdict:** the decision + one limit + "full write-up at nbertoa.com" |

## Capture

- [ ] 1920×1080 or 2560×1440, 60 fps, editor UI scaled so text is readable on a phone
- [ ] Hide personal paths, client project names, and any API keys or tokens in agent panels
- [ ] Record clean takes of the final result (no debug spam unless debug is the point)
- [ ] Keep raw clips in `media/raw/` (git-ignored)

## Edit

- [ ] Burned-in captions (most viewers watch muted)
- [ ] One key number on screen during the demo
- [ ] No intro animation, no music louder than the voice
- [ ] Thumbnail: result frame + question in 3–5 words

## Publish

- [ ] YouTube (main, unlisted is fine until the post is live)
- [ ] Short vertical cut (≤ 60 s) for LinkedIn / Shorts, if the demo reads well cropped
- [ ] Link added to the brief header table
